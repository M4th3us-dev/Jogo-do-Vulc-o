# Registro do uso de Inteligência Artificial no projeto

**Projeto:** Cratera de Vulcão com Criaturas de Lava  
**Aluno:** Matheus Lucas Gonçalves  
**RGM:** 802.387  
**Ferramentas:** Godot 4, GDScript, GitHub e ChatGPT

## Objetivo deste registro

Este documento descreve como a inteligência artificial foi utilizada como apoio durante o desenvolvimento e a publicação do jogo. O ChatGPT foi empregado para explicar conceitos, sugerir soluções, auxiliar na escrita e revisão de código e orientar procedimentos técnicos.

## Processo de desenvolvimento e aprendizagem

O projeto foi desenvolvido a partir da proposta de criar um jogo de defesa em uma cratera de vulcão. O objetivo é proteger um cristal por três minutos, impedindo que criaturas de lava o atinjam cinco vezes.

Durante o trabalho, utilizei o ChatGPT para entender a estrutura de um projeto no Godot, o papel do script em GDScript e o funcionamento de partes como movimentação, surgimento dos inimigos, ataques, temporizador e condições de vitória e derrota. As explicações foram organizadas por funções e variáveis, de modo a facilitar o estudo do código.

A IA também auxiliou na elaboração de trechos de implementação e na revisão de problemas encontrados. Por exemplo, foi identificada e corrigida a forma de escrever mensagens com várias linhas no script, evitando erros de sintaxe.

## Participação da IA

O auxílio do ChatGPT incluiu:

- Explicações sobre variáveis, funções e fluxo de execução do jogo;
- Sugestões e geração de código em GDScript para a implementação das mecânicas;
- Apoio na identificação e correção de erros;
- Orientações sobre a organização do projeto e seu envio ao GitHub;
- Criação e ajuste de arquivos de configuração para exportar o jogo para Web e publicá-lo com GitHub Actions e GitHub Pages.


## Publicação no GitHub

Na etapa de publicação, o ChatGPT auxiliou diretamente na configuração do repositório, corrigiu um problema nas strings do script e criou arquivos para automatizar a exportação Web e a implantação no GitHub Pages. Os registros dessas alterações podem ser consultados no histórico de commits e nas execuções do GitHub Actions.

## Considerações finais

A inteligência artificial foi utilizada como recurso de orientação, explicação, implementação e revisão técnica. Este registro busca deixar transparente sua participação no projeto. A experiência também contribuiu para o estudo de GDScript, da estrutura do Godot e das etapas necessárias para disponibilizar um jogo na Web.

**Observação:** este documento descreve as contribuições conhecidas da IA. A proporção exata do código escrita manualmente pelo aluno não foi medida; por isso, não é atribuída uma porcentagem de autoria.
